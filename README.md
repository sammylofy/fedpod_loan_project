# FEDPOD Cooperative Automated Loan Management System with Credit Risk Evaluation

## Overview
An automated web-based Loan Management and Credit Risk Evaluation System built for **Federal Polytechnic Ohodo (FEDPOD) Staff Multipurpose Cooperative Society**. It replaces manual flat files with automated credit scoring (300–850), Equated Monthly Installment (EMI) computation, approval workflows, and delinquency classification.

## How to Run with XAMPP MySQL

1. **Start XAMPP MySQL:**
   - Open the **XAMPP Control Panel** and start **Apache** and **MySQL**.
   - Click **Admin** next to MySQL to open `http://localhost/phpmyadmin`.
   - Create a new database named **`fedpod_loan_db`**.
